FILE 1: fossbot_gesture_control/gesture_steering.py   [MAIN SOLUTION FILE]
--------------------------------------------------------------------------------
Container path:
  /fossbot_ros2/ws_fossbot/src/fossbot_gesture_control/fossbot_gesture_control/gesture_steering.py

Base:
  Copied from the Step 4 node skeleton in the Lab 08 instructions.

Changes made to the skeleton:
  [ADDED] Helper function "finger_extended(landmarks, tip, pip)" (Step 5):
      - Checks if a finger is upright by comparing normalized image Y coords:
        returns `landmarks[tip].y < landmarks[pip].y` (smaller y = higher up).

  [EDITED] Function "classify_gesture(landmarks)" (Step 5):
      - Replaced the placeholder `return "stop"` with full gesture logic:
        1. Evaluates extended state for index, middle, ring, and pinky fingers.
        2. "forward" : index extended AND middle, ring, pinky folded.
        3. "back"    : all four fingers (index, middle, ring, pinky) extended.
        4. "left" / "right" : all four fingers folded AND horizontal distance
           `dx = landmarks[THUMB_TIP].x - landmarks[INDEX_MCP].x` exceeds 0.1
           (`dx < 0` -> "left", `dx > 0` -> "right").
        5. "stop"    : fallback default for any other/unrecognized hand pose.

  [EDITED] Function "gesture_to_twist(gesture)" (Step 6):
      - Replaced the empty TODO with velocity mapping to geometry_msgs/Twist:
        * "forward" -> twist.linear.x  = +0.2  (FORWARD_SPEED)
        * "back"    -> twist.linear.x  = -0.2  (-FORWARD_SPEED)
        * "left"    -> twist.angular.z = +0.5  (TURN_SPEED)
        * "right"   -> twist.angular.z = -0.5  (-TURN_SPEED)
        * "stop"    -> leaves Twist at all zeros (0.0, 0.0).

  [UNCHANGED from skeleton]:
      - Landmark index constants (THUMB_TIP=4 ... PINKY_TIP=20).
      - Speed constants (FORWARD_SPEED = 0.2 m/s, TURN_SPEED = 0.5 rad/s).
      - GestureSteering ROS 2 Node class:
          * Publishes Twist to `/cmd_vel` at 10 Hz (`create_timer(0.1, ...)`).
          * Loads `~/hand_landmarker.task` with `num_hands=1`.
          * Captures webcam with `cv2.VideoCapture(0)` and mirrors horizontally.
          * Draws red circles on the 21 hand landmarks + green gesture label.
          * Publishes zero Twist on Ctrl+C exit in `finally:` block.

3. ENVIRONMENT / DOCKER CHANGES (MADE ON THE LAB PC AT RUNTIME)
================================================================================
Nothing in the existing `FOSSBotEduSim` repo or `ros2_fossbot_edu` Docker image
was modified. Only the runtime launch flags and container packages differ from
Labs 05–07:

  1. Webcam passthrough in `docker run` (Step 1.2):
     - Added `--device=/dev/video0:/dev/video0` (plus `--group-add video`) so
       the container can read the host webcam. The default `start_container.sh`
       does not include this flag.
  2. In-container runtime installs (Step 1.3 & 1.4 via `container_setup.sh`):
     - Installed `mediapipe` via pip (`--break-system-packages --ignore-installed`).
     - Downloaded `~/hand_landmarker.task` into the container's home directory.
  3. Build output (generated in container during Phase 2):
     - `colcon build` generates `build/`, `install/`, and `log/` folders inside
       `/fossbot_ros2/ws_fossbot/`.


================================================================================
4. POSSIBLE IN-LAB EDITS (ONLY IF NEEDED TOMORROW)
================================================================================
All tweaks, if needed, are inside one file:
  /fossbot_ros2/ws_fossbot/src/fossbot_gesture_control/fossbot_gesture_control/gesture_steering.py

  * If webcam is not /dev/video0 (e.g., /dev/video2):
      Change `cv2.VideoCapture(0)` -> `cv2.VideoCapture(2)` (line 72).
  * If left/right steering feels mirrored:
      Swap `"left"` and `"right"` in `classify_gesture` (line 45).
  * If robot moves too fast/slow on real hardware:
      Adjust `FORWARD_SPEED` (line 17) or `TURN_SPEED` (line 18).
  * After any edit, always rebuild + source:
      cd /fossbot_ros2/ws_fossbot
      colcon build --packages-select fossbot_gesture_control
      source install/setup.bash
